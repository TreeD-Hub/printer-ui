# `src/styles`

Дизайн-токены, шрифты и общие стили компонентов TreeD Shell.

## Состав

- `foundation.css` — `@font-face`, цвета, типографика, отступы и переменные геометрии.
- `ui-kit.css` — общие классы компонентов, включая CSS-маски иконок.

## Правила

- Новые дизайн-токены добавляются в `foundation.css`.
- Кросс-экранные primitives добавляются в `ui-kit.css`.
- `ui-kit.css` подключается в `App.tsx` после стилей экранов: общий touch-контракт, состояния, шрифтовые роли и focus-visible имеют единый источник.
- Стили конкретного screen/feature остаются рядом с его компонентом или в `App.css`, если это верхнеуровневый shell layout.
- Цвета и размеры иконок задаются через CSS/currentColor, а не через inline SVG fill/stroke в компонентах.
- Базовый визуальный контракт должен оставаться совместимым с `960x544` и Playwright layout checks.

Источник визуальных правил: [00_FOUNDATION.md](../../docs/00_FOUNDATION.md).
Компоненты: [UI](../ui/README.md). Браузерные проверки геометрии: [E2E](../../e2e/README.md).

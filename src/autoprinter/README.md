# AutoPrinter

`AutoPrinterPanel` отображает состояние очереди и привязки, полученное от
`useAutoPrinter` в `App`. Панель не выполняет запросы сама и не создаёт polling.
Текущую печать по-прежнему контролирует главный экран.

- `AutoPrinterPanel.tsx` — представления «Очередь» и «Связь», действия очереди,
  повторная проверка стола и диалог кода привязки.
- `autoprinter.css` — локальная раскладка панели для canvas принтера и токены
  из `styles/foundation.css`.
- `AutoPrinterPanel.test.tsx` — проверки состава панели и вызова отдельного
  действия приостановки очереди.

DTO и правила готовности принадлежат `packages/printer-logic/autoprinter`;
polling, свежесть, pairing и результаты действий принадлежат
`core/store/useAutoPrinter`. Не выводите имя файла или владельца из UUID запуска.

# `src/printSession`

Управление выбранным файлом, текущей печатью и окном завершения в printer shell.
`usePrintSessionController` связывает библиотеку файлов с существующими командами.

`PrintCompletionFlow` постоянно смонтирован в `App`. Окно открывается после
наблюдаемого перехода `printing|paused → complete` при связи с готовым принтером.
Начальное `complete`, отмена, ошибка и завершение из устаревшего offline snapshot
не открывают окно. Каждое новое задание получает отдельное окно, даже для того же файла.

Оценка «Хорошо / Плохо» необязательна. Live-клиент сохраняет её для подтверждённой
сессии камеры через [printFeedback.ts](../core/printFeedback.ts). Mock имитирует
сохранение только в памяти текущего окна и не отправляет HTTP-запросы.
Ошибка оставляет выбранную оценку и кнопку повтора. Несохранённая выбранная оценка
блокирует повтор печати. На время операции с оценкой кнопки закрытия и повтора
заблокированы; Escape также не закрывает окно.

Повтор передаёт исходный полный относительный путь в существующий обработчик
`App` и требует подтверждения снятой детали. Командные ошибки и причины блокировки
показываются в окне. Фокусом и Escape управляет общий `useModalFocus`.

`PrintCompletionModal` получает отображаемые состояния и callbacks от flow.
Подтверждение свободного стола хранится локально в модалке; при новом задании
flow создаёт новый экземпляр окна, чтобы не переносить подтверждение между печатями.

Адресные тесты: `npm run test:ui -- src/printSession/PrintCompletionModal.test.tsx src/printSession/PrintCompletionFlow.test.tsx src/core/printFeedback.test.ts`.

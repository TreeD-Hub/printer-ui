# Scripts

`add-ui-updater.mjs OUTPUT` дополняет live UI manifest и копирует в пакет
`treed_ui_updater.py` того же выпуска. Его вызывает `release-ui.yml` перед ZIP.

`treed_ui_updater.py` запускается root worker на принтере из проверенного,
закреплённого за операцией архива. Он выполняет только публикацию UI и recovery,
сохраняет предыдущие файлы и не меняет конфигурацию оборудования.

`python -B scripts/test_treed_ui_updater.py` проверяет упаковку, установку,
следующее обновление, отказ при печати и восстановление после прерывания.
Это офлайн-проверка с моделями network/systemd, без запуска принтера.

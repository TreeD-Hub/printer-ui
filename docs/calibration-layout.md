# Стандартный шаблон калибровки

Применять по запросу «применить стандартный шаблон калибровки» или «стоковый шаблон калибровки». Образец — экран высоты по бумаге в `EddyCalibrationScreen.tsx`. Шаблон задаёт расположение и оформление; команды, проверки и порядок этапов определяет контракт конкретной калибровки.

## Геометрия

Целевой экран — `960×544`. Использовать токены [00_FOUNDATION.md](00_FOUNDATION.md) и существующие классы из [eddyCalibration.css](../src/macros/eddyCalibration.css).

| Область | Расположение |
| --- | --- |
| Шапка `.eddy-header` | Слева возврат или завершение, по центру название и отметка симуляции, справа аварийная остановка при предусмотренных сценарием условиях. Колонки: `112px / 1fr / 240px`. |
| Основной блок `.eddy-instrument` | Превью слева шириной `320px`, параметры и инструкции справа в оставшемся пространстве. Между ними вертикальная граница и отступ `--space-sm`. |
| Превью | Схема или график; подпись у нижнего края. Подробности заменяют превью в той же колонке. |
| Параметры `.eddy-instrument-controls` | Вертикальное центрирование, выравнивание текста по левому краю. Основные параметры и кнопки должны помещаться без прокрутки; кнопки не сжимаются. Для плотного блока использовать расширенный макет ниже. |
| Статус `.eddy-status` | Отдельная строка высотой `40px` под основным блоком. Ошибки и неопределённый результат остаются видимыми. |
| Подвал `.eddy-footer` | Слева «Подробнее»/«Скрыть», по центру отмена и вспомогательные действия, справа основное действие. Колонки: `240px / 1fr / 240px`. |

### Высокий правый блок

Если основные элементы не помещаются, добавить к `.eddy-workflow` класс `.eddy-workflow--tall-controls`. Правый блок занимает основной ряд и область рядом со статусом: получает дополнительно `40px + --space-xs` (`48px`). Левое превью остаётся прежней высоты; статус располагается только под ним. Шапка и подвал сохраняют позиции.

Этот режим включён для активного ручного измерения высоты с шестью кнопками TESTZ и для температурной серии. В температурной серии слева остаётся схема катушки, справа располагаются график сопла, стола и Eddy, текущие температуры и состояние серии. Не заменять расширенный макет скрытием полосы прокрутки, обрезкой содержимого или уменьшением зоны нажатия. Если расширенной высоты недостаточно, изменить композицию параметров и инструкций, сохранив их смысл и доступность всех команд. Подробности, журналы и длинные ошибки могут прокручиваться отдельно от основного блока управления.

## Текст и управление

- Инструкции в основном блоке: `--font-size-heading` (`22px`), как название экрана; шрифт `--font-family-ui`.
- Числовое значение: `--font-size-heading-large` и `--font-family-accent`. Подпись параметра: `--font-size-small`.
- Между элементами блока: `--space-sm` (`16px`); между подписью и значением: `--space-xs` (`8px`).
- Зона нажатия: минимум `48×56px`; основные кнопки имеют высоту `--control-height`.
- Для TESTZ: минусовые шаги слева, плюсовые справа. В обеих колонках величина шага убывает сверху вниз: `1 / 0.1 / 0.05 мм`. Между колонками вертикальный разделитель. Значения и ограничения брать из действующего контракта команд.
- Сохранять монохромный Nothing Pixel Terminal, существующие границы и красный цвет опасных действий.

## Переход между этапами

В Eddy после сохранения тока катушки открывается высота по бумаге, после сохранения высоты — температурная серия, после сохранения температурной кривой — проверка Z0. Переход допускается после принятой команды сохранения, наблюдённого перезапуска, восстановления готовности и подтверждения результата устройством. Для высоты также требуется подтверждение следующего этапа `temperature`, для температурной серии — `z0`.

Температурная серия запускается одной кнопкой. Во время нагрева справа показан график; при подтверждённом запросе `manual_probe` его заменяют регулировка высоты и кнопка «Подтвердить зазор». История температур продолжает собираться. После достижения целевой температуры Klipper сам заканчивает серию. UI однократно запускает сохранение только при завершённой штатной калибровке, закрытом ручном замере, не менее трёх принятых точках и новых pending-коэффициентах секции `temperature_probe btt_eddy`. Core проверяет кривую перед записью. При ошибке нет автоматического повторения команды или перехода дальше.

Переход не запускает следующую команду движения или нагрева. Ошибка, ожидание сохранения и неопределённое состояние сохраняют блокировки. Для других калибровок автопереход добавлять только по соответствующему запросу и после проверки их условий завершения.

## Применение

1. Найти активный экран и его команды. Сохранить обработчики, подтверждения, ограничения и доступность аварийной остановки.
2. Использовать указанную геометрию и токены. Не создавать отдельные размеры и новый компонент, если достаточно существующей разметки и общих стилей.
3. Проверить diff. Для изменения логики перехода выполнить адресный тест ожидания, успешного подтверждения и отсутствия автоматического запуска следующей операции.

Визуальная проверка и проверка на устройстве выполняются по правилам проекта и действующему разрешению. Документ не подтверждает, что конкретный экран проверен на оборудовании.
